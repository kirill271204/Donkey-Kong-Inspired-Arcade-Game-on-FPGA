# Donkey-Kong-Inspired-Arcade-Game-on-FPGA
This project provides the design of a Donkey Kong-inspired arcade game constructed entirely in Verilog HDL and deployed on the Digilent Nexys 4 DDR FPGA development board. The game outputs a 640×480 VGA signal at 60 Hz and implements the game features all in synchronous hardware with no software or processor involved.
