# Donkey-Kong-Inspired-Arcade-Game-on-FPGA
## Overview
This project Donkey Kong-inspired arcade game designed entirely in Verilog HDL and deployed on the Digilent Nexys 4 DDR FPGA development board. The game outputs a 640×480 VGA signal at 60 Hz and implements animated sprites, gravity-based jumping, rolling barrel obstacles, collision detection, score tracking, and end-screen overlays — all in synchronous hardware with no software or processor involved. The player navigates Mario from the bottom of the screen across seven sloped girder platforms, connected by eight ladders, to reach a trophy at the top — while dodging a continuous stream of barrels thrown by Donkey Kong.
